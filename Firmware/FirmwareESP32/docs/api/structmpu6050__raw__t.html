Detailed Description

Lectura cruda de los siete canales consecutivos del MPU6050.

Los valores son muestras signed de 16 bits antes de convertirlas a g, DPS y grados Celsius. La escala configurada es +/-2 g, +/-250 DPS y temperatura interna del MPU6050.
