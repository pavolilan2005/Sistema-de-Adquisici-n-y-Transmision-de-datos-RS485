Detailed Description

Firmware transmisor LoRa para ESP32 clásico, SX1278 y sensores I2C.

El módulo inicializa el bus I2C, lee aceleración, velocidad angular y temperatura del MPU6050, y añade temperatura, presión, humedad y resistencia de gas del BME680 cuando este sensor está disponible. El paquete ASCII se transmite mediante el SX1278 con el perfil compatible con receptor_lora_tft.

Flujo de ejecución

app_main() configura el LED, inicializa sensores y radio y entra en un ciclo que toma muestras, construye el payload, lo transmite y aumenta SEQ únicamente si el envío terminó correctamente.

Dependencias

La API Bosch adaptada para ESP-IDF realiza la compensación del BME680; el componente i2c_bus administra el bus compartido con el MPU6050.

Function Documentation

◆ app_main()

void app_main ( void )

Punto de entrada de ESP-IDF para el firmware transmisor.

Configura el LED de actividad, inicializa sensores y radio y repite lectura, serialización y envío. Con TX_PERIOD_MS == 0 no añade una pausa artificial entre paquetes. El LED permanece encendido durante cada TX y SEQ solo se incrementa después de una transmisión confirmada.

Note
El MPU6050 es obligatorio para transmitir; el BME680 es opcional.
